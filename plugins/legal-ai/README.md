# 智能法务

BestSign 智能法务在 AI Agent 宿主（任何支持 MCP 的客户端）上的能力入口。插件以**技能（Skill）**为单位组织能力，
所有技能共用同一个 Legal AI MCP 服务与一次 OAuth 授权——装一次、授权一次，即可使用插件内全部技能。

本版本包含 **1 个技能**：合同深度审查。后续版本会陆续增加其他法务技能，届时升级本插件即可，无需新增连接。

## 合同深度审查（deep-review）

上传本地合同，由 BestSign Legal AI 云端法务大模型执行深度风险审查，并生成结构化审查报告。

### 能力介绍

- **智能解析**：自动识别合同签约主体与适用法域，推荐审查偏好
- **立场审查**：支持以甲方 / 乙方 / 中立第三方或自定义立场逐条审阅合同漏洞与履约风险
- **多法域**：中国大陆、中国香港、美国、日本及通用外国法
- **多语言报告**：中文、英文、日文
- **成果交付**：审查完成后一键下载合同原文（Word 可在线批注修订）与审查报告 PDF

### 使用方法

1. 在对话中提供本地合同文件路径（支持 `.docx` / `.pdf`），说明需要"深度审查"
2. 按提示确认您的**审查立场、适用法域、报告语言**（可直接回复"全部默认"）
3. 等待约 3–8 分钟，审查完成后回复"下载"，文件默认保存至桌面

> Word 格式合同云端会自动启用可编辑模式，支持后续对条款在线修改。

## 使用前提（全插件共用）

- 拥有 BestSign Legal AI 账号（如无，请先在官网注册并开通相应工作空间）
- 首次连接时宿主会自动弹出授权页面，选择要授权的工作空间并确认即可，全程无需手工填写任何密钥
- 授权对整个 Legal AI 服务生效，插件内其他技能不再重复弹窗

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 提示 401 / 未授权 | 授权已过期，重新完成授权即可，无需重装插件（影响整个插件，不只某一个技能） |
| 审查时间超过预期 | 合同篇幅较长时属正常现象，记下任务 ID，稍后让助手查询结果即可 |
| 报告语言/法域选不了想要的 | 当前仅支持上述法域与语言，其他法域可选择"通用外国法" |
| 工具列表出现重复 | 插件与你在宿主里手动配置的同一服务指向了同一端点，二选一保留即可 |
| 换端点后要重新授权 | 授权 Token 按端点 URL 归键：只有域名/路径变化才需重授权，**改服务器名不需要** |
